01

What We're Building

This module answers a single question for every site in a company's portfolio: How much does this site impact nature, and how much does it depend on it?

It takes ENCORE activity-based data and location-specific State of Nature data, combines them using a defined methodology, and surfaces results as four views: a portfolio dashboard, a site list, a site impact view, and a site dependency view.

Think of it this way: ENCORE tells you what pressures a cement plant typically exerts. State of Nature data tells you whether the ecosystem at this specific cement plant's location is already stressed. Together they tell you if this site is actually a problem — or just theoretically one.

Why We Beat Nala

Nala is CSRD-first. We are TNFD-first. This single difference changes what we surface, how we score, and what actions we recommend.

CSRD ESRS E4 materiality as primary output
Impact Level informs reporting obligation, not financial risk
Dependency Level shown but not connected to risk pathway
No explicit link to prioritization framework
GHG Emissions included in pressures (duplicates TCFD)
State of Nature sourced generically
No scenario sensitivity
✦ Our Build

Dependency Level explicitly feeds TNFD "dependency → transition risk" translation

Inputs (what feeds this module)

  • L1: Site inventory (ID, name, location, activities)
  • ENCORE API: Pressure + dependency ratings per SASB × Biome
  • WRI Aqueduct: Water stress per lat/lng
  • IBAT / PBF: MSA + BII scores per lat/lng

Outputs (what this module produces)

  • Overall Impact Level per site (VL → VH + 0–10 score)
  • Dependency Level per site per category
  • Composite Priority Score for A3 triage
  • TNFD Core Metrics data points (C3.0, A5.3, etc.)

05

Computed Logic

All computed values are derived on-the-fly from the 3 tables above. Never store these — recompute on read to keep logic in one place.

Step 1: Enum → Numeric Conversion

Used throughout. Always apply this mapping before any arithmetic:

VL = 1 | L = 2 | M = 3 | H = 4 | VH = 5

Step 2: Four Nature Impact Scores

Nature Impact Environmental Pressure (EP) State of Nature (SoN)
Increased Water Scarcity ep_water_use water_scarcity_level
Increased Water Pollution MAX(ep_toxic_emissions, ep_nutrient_emissions) water_pollution_level
Loss of Intact Natural Land ep_land_use land_degradation_level
Loss of Important Biodiversity ep_overall_pressure_biodiversity biodiversity_loss_level

Each Nature Impact has an Individual Impact Level = EP_numeric + SoN_numeric, then threshold:

2 → VL  |  3–4 → L  |  5–6 → M  |  7–8 → H  |  9–10 → VH

Step 3: Overall Impact Score (Nala Formula)

Impact Score Calculation
raw_sum = Σ (EP_i + SoN_i) across 4 Nature Impacts

impact_score = (raw_sum − 4) / (40 − 4) × 10
is_min = 4   (4 impacts × minimum numeric sum of 1+1=2... but baseline is actually 4 because VL+VL=2 per impact × 4 = 8; Nala uses 4 as minimum total EP score pre-SoN combination — use is_min=4 as stated)
is_max = 40  (4 impacts × VH+VH = 5+5=10 each × 4 = 40)
Output range: 0.0 → 10.0

Step 4: Overall Impact Level

0.0 – 2.0  →  Very Low
2.0 – 4.0  →  Low
4.0 – 6.0  →  Moderate
6.0 – 8.0  →  High
8.0 – 10.0 →  Very High

Step 5: Biodiversity Loss Level (for SoN input)

min_score = MIN(msa_score, bii_score)   // both in 0–1 range

min_score > 0.80  →  VL  (Very Low Biodiversity Loss)
min_score 0.60–0.80  →  L
min_score 0.40–0.60  →  M
min_score 0.20–0.40  →  H
min_score ≤ 0.20  →  VH  (Very High Biodiversity Loss)

Step 6: Dependency Levels (3 categories)

Each Dependency Level = matrix lookup of (ENCORE Dependency Rating) × (relevant SoN level):

ENCORE Dep →
SoN Loss ↓		 VL L M H VH
VL Loss VLVLVLVLL
L Loss VLVLLMH
M Loss VLLMHH
H Loss LMHHVH
VH Loss MHHVHVH

Apply this matrix for:

  • Water Supply Dependency Level → dep_water_supply × water_scarcity_level
  • Soil Retention Dependency Level → dep_soil_sediment_retention × land_degradation_level
  • Overall Biodiversity Dependency Level → dep_overall_dependency_biodiversity × biodiversity_loss_level

Step 7: TNFD-Specific Derived Fields (our additions over Nala)

// Composite Priority Score for A3 triage (0–100)
composite_priority_score = (impact_score × 5) + (dependency_risk_score × 5)
  where dependency_risk_score = MAX(water_dep_level, soil_dep_level, biodiv_dep_level) as numeric

// TNFD Priority Flag
tnfd_priority = (overall_impact_level IN ['Moderate','High','Very High'])
             OR (any dependency_level IN ['High','Very High'])

// Priority Tier for A3
Tier 1: composite_priority_score > 75
Tier 2: composite_priority_score 50–75
Tier 3: composite_priority_score < 50

08

Beyond Nala — TNFD-Native Additions

These are features Nala doesn't have. Build them from day one — they are what make this a TNFD tool, not just a CSRD tool.

Addition 1: TNFD Priority Tier Badge (not CSRD Materiality)

Replace Nala's "CSRD Expected/Not Expected" badge with a TNFD Priority Tier (1/2/3) derived from the Composite Priority Score. This directly feeds A3 and is the output financial analysts actually need.

Addition 2: A3 Handoff Card

On the site detail view, after the Impact Level table, show a "Risk Pathway" section: a collapsible panel that maps the site's Impact Level and Dependency Levels to TNFD risk categories (Physical Risk, Transition Risk, Systemic Risk) and shows which A3 risk pathways to investigate next. This is the explicit LEAP bridge Nala is missing.

Addition 3: Composite Priority Score

A single 0–100 number combining Impact Score and Dependency Risk. Shown on the All Sites list as a sortable column. Enables instant triage without reading individual ratings. Nala shows impact level separately from dependency level with no combined score.

Addition 4: Data Confidence Indicator

Show a small data quality flag (High/Medium/Low) on each State of Nature input, based on data source resolution. When confidence is Low, show a tooltip explaining what data was used as a proxy. This is critical for TNFD disclosure documentation and builds user trust in the methodology.

Addition 5: ENCORE Attribution Block

Automated, always-visible ENCORE attribution on every screen that uses ENCORE data (required by CC BY-SA 4.0 license). Include DOI link.
